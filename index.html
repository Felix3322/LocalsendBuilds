⚙️ Install MSIX via PowerShell (Fix 0x800B010A)

  • Download the .msix file, then right-click it → Copy as path.
  • Open PowerShell (normal user is usually enough, Admin only if policy requires).
  • Paste and run this script (replace the path):
    $msix = "C:\Users\***\Downloads\localsend_app_0.msix"
$sig  = Get-AuthenticodeSignature -FilePath $msix
if ($sig.Status -ne 'Valid' -or -not $sig.SignerCertificate) { throw "Cannot read signing certificate from MSIX." }
$cer = Join-Path $env:TEMP "localsend_msix_signer.cer"
Export-Certificate -Cert $sig.SignerCertificate -FilePath $cer | Out-Null
Import-Certificate -FilePath $cer -CertStoreLocation "Cert:\CurrentUser\TrustedPeople" | Out-Null
Add-AppxPackage -Path $msix
  • If you still get 0x800B010A, also import the cert to Cert:\CurrentUser\Root and retry.
  • If you see a policy error, enable sideloading in Settings → Privacy & Security → For Developers → Sideload apps.
  • Once installed, search for LocalSend in Start Menu and launch it normally.
