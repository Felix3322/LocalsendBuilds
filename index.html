Windows

Use the portable ZIP without installation. For unsigned MSIX, enable Developer Mode and run Add-AppxPackage -Path ".\LocalSend.msix" -AllowUnsigned.

Android

Choose the APK matching the device CPU. Most current phones use arm64-v8a. Android may ask for permission to install unknown apps.

Linux

Use DEB on Debian and Ubuntu, AppImage for a portable package, or the tar.gz bundle for manual installation.
